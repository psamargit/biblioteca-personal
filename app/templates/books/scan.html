Escanear Código de Barras

Usa la cámara de tu dispositivo para escanear el código de barras ISBN de un libro. El sistema buscará el libro en tu biblioteca o te permitirá agregarlo con información de Google Books.

Instrucciones
  1. Haz clic en "Iniciar Escáner" y permite el acceso a la cámara
  2. Coloca el código de barras ISBN del libro frente a la cámara
  3. Mantén el código de barras enfocado y bien iluminado
  4. El sistema detectará automáticamente el código
  5. Si el libro existe en tu biblioteca, te mostrará los detalles
  6. Si no existe, podrás agregarlo con información de Google Books
Nota: Esta función requiere una cámara web y permisos de acceso. Funciona mejor con códigos de barras ISBN-13 (13 dígitos).
